# data

| Item | Use |
|---|---|
| `qss_profile_Shanghai_p0.npz` | Cached QSS speed profile for the default setup p0 (133.9 s lap). Rebuild with `scripts/build_qss_profile.py` |
| `demos/` | Demonstration datasets for BC, keyed by hash of the demo-relevant sources. Git-ignored, regenerated by `scripts/collect_demos.py` |
| `tracks_extra/` | C2a track geometry in TUM format (`# x_m,y_m,w_tr_right_m,w_tr_left_m`) converted from bacinger/f1-circuits (MIT, commit 8094e95) by `scripts/fetch_track_geometry.py`, one JSON provenance sidecar per track (no timestamp: re-runs are byte-identical) and `LICENSE-bacinger-f1-circuits.md` (verbatim upstream MIT notice). Widths are a PLACEHOLDER constant (`width_assumed: true`). `raw/` holds the downloads and is git-ignored |
